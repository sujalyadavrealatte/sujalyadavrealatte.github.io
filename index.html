Ramky Estates

ramkyestates.com
Stack
WordPress · custom theme · mu-plugins · ACF · Yoast · WP Rocket · nginx
Scope
Incident response + SEO build

Hyderabad developer site that was serving a different page to Google than to visitors. Cleaned the compromise, then implemented the client's full on-page SEO specification across 79 pages.

  • Found the cloaker. A root-level injector fired on Googlebot user agents, crawler IP ranges and Google referrers, serving an Indonesian gambling page while cached pages looked clean. Also found an unauthenticated web shell in wp-admin and a publicly downloadable 5.6 GB full-site backup.
  • ALT inheritance. The theme hard-coded image ALTs, so a permanent mu-plugin rewrites them from the Media Library through an output buffer that runs inside WP Rocket's own buffer.
  • Schema and headings. Per-page JSON-LD through an ACF field plus mu-plugin, and one H1 per template across every page.
  • Recovery. Restored Yoast taxonomy meta wiped by a write that saved one key at a time, rebuilding the lost fields from archived copies.

Sri Lotus Developers

lotusdevelopers.com
Stack
CodeIgniter · WordPress · nginx · php-fpm · MySQL · Ubuntu VPS
Scope
Two apps, one domain

Mumbai luxury developer running a CodeIgniter main site with a WordPress blog mounted at /blogs on the same domain, on a root-SSH VPS.

  • Redirect loop. The blog's site URL had been set to the www host while nginx held a hard www → non-www 301 for the whole domain, so every request bounced forever — and wp-login posted to www too, making the admin UI useless. Repaired directly in the database.
  • Unknown paths return HTTP 200 on the CodeIgniter side, so status codes alone can't tell you whether a URL exists. Documented for whoever audits it next.

WP MCP Bridge

WordPress plugin

Connects any WordPress site to an AI coding agent using nothing but wp-admin access — the common case on client sites with no FTP or hosting panel. 27 tools covering the REST API, Elementor data, post meta, options, scoped file read/write and read-only queries. Every write returns a backup ID, and PHP or .htaccess changes revert themselves automatically if the site fatals.
